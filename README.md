# Blog

A clean, responsive blog website built using **React** and **CSS Modules**, inspired by Medium-style layouts. It features dynamic routing, post previews, image-backed post headers, and a minimalist design.

## Features

-  Home page listing blog posts
-  Single post pages with unique content and background images
-  Stylish header section with image backgrounds
-  Clean and responsive design using CSS Modules
-  Mobile-friendly layout
-  React Router for smooth navigation
-  Easily extendable for dynamic data or backend integration

## 🔧 Tech Stack

- React
- React Router DOM
- CSS Modules
- JavaScript (ES6+)
